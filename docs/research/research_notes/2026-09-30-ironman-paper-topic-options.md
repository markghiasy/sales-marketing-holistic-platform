# Choosing a first Ironman paper

2026-09-30. Advisory comparison for an urgent supervisor proposal, not a novelty or publication guarantee. No private database, environment file, or customer grading records were accessed. Advisor fit remains unknown.

## Recommendation

Choose **evidence-grounded multi-requirement contact/resource retrieval under incomplete professional-network evidence**, framed initially as applied IR and a controlled system study. Do not commit the abstract to a new search algorithm, strategic business success, or superiority. Scope the paper to whether explicit requirement accounting changes supported retrieval quality and cost; the graph interface motivates the problem but is not the primary contribution.

**Bounded RQ:** On a frozen professional-network evidence collection, under shared evidence rules and resource limits, how does explicit requirement-state-guided exploration change supported requirement coverage and unsupported recommendation rates relative to fixed expansion, aspect-diversified reranking, and an adaptive retrieval controller?

Use one query family first: finding complementary people/resources for several stated needs. Preserve distinctions between one person satisfying all conditions and several people collectively satisfying them. “Not found within budget” is not absence from the network. Start with supplied structured requirements; test natural-language decomposition separately.

## Novelty boundaries

**Retrieval is crowded.** xQuAD already tracks aspect coverage; team-formation work already trades new skill coverage against communication cost. ARK, ToG-2, and GraphSearch already adapt graph/text exploration to observations or missing evidence. The [primary-source comparison](2026-09-30-adaptive-search-related-work.md) and [coverage/team note](2026-09-29-short-paper-novelty-boundary.md) constrain the claim. Potential value lies in a carefully specified professional-network task, support semantics, and a measured controller comparison, not renaming these mechanisms.

**Temporal memory is not a safer novelty shortcut.** [Zep](https://arxiv.org/html/2501.13956v1) already describes temporal graph memory. [Hindsight's ACL demonstration](https://aclanthology.org/2026.acl-demo.27/) integrates retaining, recalling, reflecting and graph/temporal retrieval. [LongMemEval](https://arxiv.org/abs/2410.10813) includes updates and temporal reasoning. [TAPE](https://icde2026.github.io/demo-papers.html) is an accepted temporal personal-agent memory demo; only its official listing was checked here.

Recent primary abstracts further narrow possible gaps: [RECON](https://arxiv.org/abs/2607.16716) covers cascading invalidation and surviving independent support; [MemConflict](https://arxiv.org/abs/2605.20926) distinguishes temporal, factual and conditional conflicts; [Forgetting Without Restarting](https://arxiv.org/abs/2609.04875) proposes provenance-guided replay across derived execution state; [TRACE](https://arxiv.org/abs/2609.33517) studies admitting still-valid memory after intervening changes. These preprints require full-method review before choosing a correction contribution; their results were not reproduced here. Graphiti bugs alone do not establish a new memory architecture.

**Human review is established ER practice.** [Magellan's primary project/paper](https://pages.cs.wisc.edu/~anhai/papers1/magellan-sigmod19.pdf) and [data-driven supervision with human feedback](https://arxiv.org/abs/2111.10497) preclude generic novelty claims for human-in-the-loop resolution. A contribution would require a demonstrated decision policy, workload reduction, or transferable failure analysis.

## Fastest defensible next milestone

Send a proposal abstract now, using future evaluation language. Build a diagnostic pilot, then freeze a held-out protocol before tuning. Share graph information, source eligibility, model, and budgets across methods; measure supported coverage, unsupported assertions, evidence-path validity and actual cost. Include simple tasks where adaptation may waste resources. Avoid an LLM-only judge or synthetic-only industrial claims.

Refresh stale manuscript status: the older temporal draft says Graphiti was never executed, superseded by the later isolated trial. Its seven-versus-three diagnostic cases compare intentionally incomplete representations and are not strong retrieval evidence. Neither that result nor local database timings belong as proof of the proposed retrieval method.
