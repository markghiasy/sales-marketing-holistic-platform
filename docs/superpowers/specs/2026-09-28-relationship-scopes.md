## Scope contract
GraphQuery adds scopes (CSV subset direct,explicit,project,organization; default direct,explicit), scope_window (0/30/90/180 days; default0), scope_sort (recent/frequency/name; defaultrecent), min_sessions (integer0..1000; default0). Empty scopes means focus only. Invalid scope rejects400. Legacy depth/min_activity accepted for old URLs but do not control new expanded results. Agent internal neighborhood tool may retain boundedhop traversal; do not claim every internal algorithm changed.

Four scopes are overlapping evidence categories, not closeness levels. Direct: recorded person-to-person contact or directly observed messages; metrics belong to that exact pair. Explicit: completed collaboration/introduction claims and at most one evidenced intermediary via person links where at least one leg is collaboration/introduction. Preserve roles/direction; never call an indirect path completed introduction to the focus. Possible introduction remains unconfirmed. Project: shared Project member context. Organization: shared Works at/Advises context, labeled affiliation rather than guaranteed colleague/acquaintance. For project/organization focus, show its evidenced members/affiliates in corresponding scope.

A path uses eligible source-backed claims only. Current/history rules and effective/known dates remain. Nonowner focus must not traverse owner. Every selected person retains overlapping scope labels and complete representative paths, not one global visited result. Known disjoint membership periods may appear in history only, labeled different periods; unknown dates mean overlap unknown. Pending paths (explicitly enabled) never upgrade confirmed status.

Event recency derives from message/event time, not import/review time. Shared affiliation is not an interaction event. min_sessions affects direct scope only, not candidate membership in other scopes; missing pair metrics null. Window filters event scopes only; shared contexts carry duration/overlap and remain visible with explanatory UI. Recent/frequency/name sorting uses deterministic values; no global familiarity/probability score. Actual edge length only path details.

Projection limits remain50nodes/100edges explorer,8/12compact. Expansion includes complete path bundles and reports omitted candidates/paths. Synthetic message-derived contact edges must expose resolvable source messages through evidence endpoint. Compact remains existing slice; roundtrip carries new scope settings.
